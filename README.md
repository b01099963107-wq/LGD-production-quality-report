# LGD-production-quality-report

# 생산·품질 조회 및 3D 설비 보고서 웹 서비스

* **날짜:** 09월14일
* **실행 환경:** Google Colab
* **개발 언어:** Python, HTML, CSS, JavaScript

## 사용 라이브러리 및 도구

| 라이브러리·도구         | 사용 목적                                 |
| ---------------- | ------------------------------------- |
| Flask            | 웹 서버 실행 및 생산·품질 조회, 보고서 API 구현        |
| Werkzeug         | 웹 서버 구동                               |
| Three.js 0.170.0 | 패널 검사·이송 설비의 3D 화면과 애니메이션 구현          |
| OrbitControls    | 마우스로 3D 화면 회전 및 확대·축소                 |
| IPython.display  | Colab에서 외부 접속 링크 표시                   |
| Python 표준 라이브러리  | JSON 저장, 날짜 처리, 파일 관리, 다운로드 및 프로세스 실행 |
| Cloudflared      | Colab 서버에 외부에서 접속할 수 있는 임시 URL 생성     |

※ Flask가 설치되지 않은 경우 코드에서 3.1.2 버전을 설치합니다.

## 설명

교육용 가상 데이터를 활용해 생산 실적과 품질 현황을 조회하고, 조회 근거를 바탕으로 보고서를 작성·보관하는 웹 서비스입니다. Google Colab에서 전체 코드를 한 셀로 실행하면 웹 서버가 시작되고 외부 접속 주소가 출력됩니다.

### 주요 기능

* **생산·품질 조회:** 시작일, 종료일, 생산라인 A/B/전체 조건으로 LOT 기록을 조회합니다.
* **핵심 지표 표시:** 목표량, 생산량, 검사량, 불량 수량과 달성률·불량률을 표시합니다.
* **불량률 시각화:** 일자별 불량률을 막대 형태로 보여줍니다.
* **설비 이력 조회:** 조회 기간에 발생한 설비 사건과 해제 여부, 메모를 확인합니다.
* **3D 설비 표시:** 금속 외관, 투명 커버, 롤러, 검사 헤드와 상태등을 갖춘 설비 모형 및 패널 이송을 표현합니다.
* **보고서 작성:** 조회 수치와 설비 사건을 정해진 서식에 넣어 초안을 생성합니다.
* **검토 및 보관:** 보고서 본문을 수정하고 검토 여부를 저장하며, 생성 당시의 조회 근거를 함께 보관합니다.
* **파일 다운로드:** 마지막 저장본의 보고서는 TXT로, 조회 근거는 JSON으로 내려받습니다.

### 계산 기준

* 생산 달성률 = 생산량 합계 ÷ 목표량 합계 × 100
* 불량률 = 불량 수량 합계 ÷ 검사량 합계 × 100
* 분모가 0이면 비율을 계산하지 않고 `—` 또는 `판단 불가`로 표시합니다.

### 실행 방법

1. Google Colab에서 새 노트북을 생성합니다.
2. 전체 Python 코드를 하나의 코드 셀에 붙여넣고 실행합니다.
3. 출력된 **디스플레이 실습 화면 열기** 링크에 접속합니다.
4. 날짜와 라인을 선택한 뒤 **조회 적용**을 누릅니다.
5. **보고서 초안 만들기**를 누르고 내용을 검토·수정한 후 저장합니다.

### 데이터 및 동작 안내

* 예제 데이터는 2026년 09월08일~09월09일의 가상 LOT 기록입니다.
* 현재 모의 상태는 라인 A가 정상 28°C, 라인 B가 온도 주의 42°C이며, 전체 조회에서는 라인 A를 표시합니다.
* 3D 패널 이동은 시각적 표현이며 생산·검사 수량을 증가시키지 않습니다.
* 보고서 초안은 정해진 서식으로 생성하며 별도 LLM API를 호출하지 않습니다.
* 보고서는 `/content/04_lgd_web/04_reports.json`에 저장됩니다. Colab 런타임이 삭제되면 파일이 사라질 수 있으므로 필요한 결과는 내려받습니다.
* 외부 접속을 유지하려면 Colab 런타임이 실행 중이어야 하며, 재실행 시 접속 주소가 변경될 수 있습니다.
